# AI Video Editor on HuggingFace Spaces

## 🎬 Chat-Powered AI Video Editor

A free, browser-based video editor with AI commands.

### Features
- 💬 Type commands in plain English
- ⚡ Auto scene detection
- 🔇 Silence removal
- 📝 AI captions
- 🎵 Background music
- 🖼️ Auto thumbnails

### How to Use
1. Upload a video
2. Type commands like "add jump cuts"
3. Download your edited video

### Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
